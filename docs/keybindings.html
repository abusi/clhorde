Tip

Type :review then press Tab to expand a template. Type @feature to tag the prompt. Use /path/to/dir: prefix to set a working directory. The input bar supports multi-line editing and grows dynamically up to 10 lines.

Quick Prompts

When viewing a running prompt, configured quick prompt keys (e.g., g for "let's go") send messages instantly without entering interact mode. See quick prompts config.

Filter Mode

Live-filter prompts by text and/or @tag. Case-insensitive. Supports AND logic for multiple @tag tokens.

KeyActionDescription

Tab Switching (any tab)

Normal

The TUI groups its three top-level views in a tab bar: Prompts (default), Drafts, and Workflows. Switch from Normal mode with the digit keys.

KeyActionDescription
1tab_promptsShow the Prompts tab (the original list/output split)
2tab_draftsShow the Drafts tab (OpenSpec changes without a .clhorde-ready marker)
3tab_workflowsShow the Workflows tab (queued + active + recent terminal)
EscbackFrom Drafts/Workflows, returns to Prompts

Drafts Tab

Drafts

One row per openspec/changes/<X>/ without a marker. Polled live from the scheduler control socket; freshness shown in the title bar.

KeyActionDescription
j / Down—Next draft
k / Up—Previous draft
g—Top
G—Bottom
r—Force a refresh from the scheduler
Q—Queue this draft (writes .clhorde-ready)
E—Continue exploring — switches to Prompts + Insert with <scheduler-root>: seeded
R—Open proposal.md (fallback design.md) in $PAGER
?—Help overlay
q—Quit (confirms if workers active)

Workflows Tab

Workflows

One row per workflow (queued, running, recently archived/cancelled/failed). Status is color-coded; a yellow · blocked suffix tags any workflow waiting on inter-workflow deps.

KeyActionDescription
j / k—Navigate
g / G—Top / bottom
Enter—Open the detail overlay (per-section DAG)
r—Force a refresh
X—Cancel this workflow (also unqueues if still queued)
T—Inline retry-section prompt (accepts dotted decimals like 3.2)
R—Open proposal.md / design.md in $PAGER
?—Help overlay
q—Quit

Workflow Detail Overlay

Detail

Press Enter on a workflow to open. Shows each apply-DAG node (id, label, state, prompt id, exit code, deps) plus the verify and archive singletons. Updates live via push events.

KeyActionDescription
j / k—Scroll detail
gg / G—Top / bottom
r—Force-refresh detail (push updates run continuously regardless)
X—Cancel the open workflow
T—Open inline retry-section prompt for the open workflow
R—Open proposal.md / design.md in $PAGER
Esc / Enter—Close overlay
Where the data comes from

Drafts and Workflows are populated over the scheduler control socket at ~/.local/share/clhorde/scheduler.sock. If the scheduler isn't running, the panes show a "scheduler not reachable — start with: clhorde-scheduler daemon" banner. The Prompts tab is unaffected.

Custom Keybindings

All keybindings shown above are defaults. Override any of them in ~/.config/clhorde/keymap.toml. Only specify what you want to change—unspecified keys keep their defaults. See the configuration reference for details.
