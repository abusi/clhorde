# M1: Output Viewer with ANSI Rendering

**Epic:** [Epic 3 — Prompt Detail](../epic-3-prompt-detail.md)
**Priority:** P0
**Depends on:** Epic 2 M3

## Description

Build the output viewer for one-shot prompts. Render the collected text output with ANSI escape code support (colors, bold, underline) in the content area.

## Tasks

- [x] Create output viewer component in the content area (shown when a one-shot prompt is selected)
- [x] Fetch full output via `GET /api/prompts/:id/output` on selection
- [x] Parse ANSI escape codes and render as styled HTML `<span>` elements (use a lightweight ANSI-to-HTML library or write a minimal parser)
- [x] Stream live output via WS `OutputChunk` events for running prompts
- [x] Auto-scroll to bottom as new output arrives (with toggle to disable, like TUI `f` key)
- [x] Show prompt metadata header: ID, status, mode, start time, duration
- [x] Handle empty output state ("Waiting for output..." for running, "No output" for completed)
- [x] Monospace font, dark background, matching TUI aesthetic

## Acceptance Criteria

- One-shot prompt output displays with correct ANSI colors
- Live output streams in real time for running prompts
- Auto-scroll works and can be toggled
- Completed prompt output loads in full on selection
