# M2: xterm.js Integration for PTY Prompts

**Epic:** [Epic 3 — Prompt Detail](../epic-3-prompt-detail.md)
**Priority:** P0
**Depends on:** Epic 1 M7, Epic 2 M3

## Description

Integrate xterm.js to render interactive PTY prompt output in the browser. Feed base64-decoded PTY bytes from the WebSocket into xterm.js for full terminal emulation.

## Tasks

- [x] Vendor xterm.js (+ xterm-addon-fit, xterm-addon-web-links) into `static/lib/` or load from CDN with integrity hash
- [x] When an interactive prompt is selected, create an xterm.js `Terminal` instance in the content area
- [x] Subscribe to PTY bytes via WS: send `{ "type": "Subscribe", "prompt_id": N }`
- [x] Decode base64 PTY bytes and write to the xterm.js terminal
- [x] Handle terminal resize: use `xterm-addon-fit` to match container size, send resize event to daemon if supported
- [x] Forward keyboard input from xterm.js to the daemon via `POST /api/prompts/:id/input` or WS `SendInput`
- [x] Unsubscribe from PTY bytes when navigating away from the prompt
- [x] Clean up xterm.js terminal instance on navigation
- [x] For completed interactive prompts: show the final ring buffer snapshot (replay last 64KB of PTY bytes)

## Acceptance Criteria

- Interactive prompt shows a working terminal emulator in the browser
- Full Claude Code TUI is visible and usable (colors, cursor, scrollback)
- Keyboard input is forwarded to the PTY
- Terminal resizes with the browser window
- No memory leaks when switching between prompts
