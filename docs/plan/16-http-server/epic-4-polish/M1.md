# M1: Store Management View

**Epic:** [Epic 4 — Polish](../epic-4-polish.md)
**Priority:** P1
**Depends on:** Epic 1 M5, Epic 2 M2

## Description

Build a store management page that mirrors `clhorde-cli store` functionality — list persisted prompts, view counts by status, and perform drop/keep/clean operations.

## Tasks

- [x] Add "Store" navigation item (tab or sidebar link)
- [x] Fetch store data via `GET /api/store` and `GET /api/store/count`
- [x] Display persisted prompt list with status, timestamp, and truncated text
- [x] Show status counts as summary cards (Completed: N, Failed: N, Pending: N)
- [x] Add action buttons:
  - "Drop All" — `POST /api/store/drop` with `{ "filter": "all" }`
  - "Drop Completed" — `POST /api/store/drop` with `{ "filter": "completed" }`
  - "Drop Failed" — `POST /api/store/drop` with `{ "filter": "failed" }`
  - "Keep Completed" — `POST /api/store/keep` with `{ "filter": "completed" }`
  - "Clean Worktrees" — `POST /api/store/clean-worktrees`
- [x] Confirm dialog for destructive actions (drop)
- [x] Show storage directory path from `GET /api/store/path`
- [x] Refresh store data after any mutation

## Acceptance Criteria

- Store view shows all persisted prompts with status counts
- Drop/keep actions work and update the view
- Clean worktrees reports count of cleaned items
- Destructive actions require confirmation
