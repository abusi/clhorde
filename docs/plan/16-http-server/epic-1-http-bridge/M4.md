# M4: REST API — Prompt Action Endpoints

**Epic:** [Epic 1 — HTTP Bridge](../epic-1-http-bridge.md)
**Priority:** P0
**Depends on:** M3

## Description

Implement the mutation REST endpoints for submitting prompts and controlling workers.

## Endpoints

| Method | Path | Maps to | Description |
|--------|------|---------|-------------|
| `POST` | `/api/prompts` | `SubmitPrompt` | Submit a new prompt |
| `POST` | `/api/prompts/:id/input` | `SendInput` | Send follow-up input |
| `POST` | `/api/prompts/:id/kill` | `KillWorker` | Kill running worker |
| `POST` | `/api/prompts/:id/retry` | `RetryPrompt` | Retry prompt |
| `POST` | `/api/prompts/:id/resume` | `ResumePrompt` | Resume with `--resume` |
| `DELETE` | `/api/prompts/:id` | `DeletePrompt` | Delete a prompt |
| `POST` | `/api/prompts/:id/move-up` | `MovePromptUp` | Move pending prompt up |
| `POST` | `/api/prompts/:id/move-down` | `MovePromptDown` | Move pending prompt down |

## Tasks

- [ ] Implement `POST /api/prompts` — accept JSON body `{ "text": "...", "mode": "interactive|one-shot", "worktree": bool, "cwd": "optional/path" }`, return created prompt info
- [ ] Implement `POST /api/prompts/:id/input` — accept `{ "text": "..." }`, return `200`
- [ ] Implement `POST /api/prompts/:id/kill` — return `200` on success
- [ ] Implement `POST /api/prompts/:id/retry` — return new/updated prompt info
- [ ] Implement `POST /api/prompts/:id/resume` — return new/updated prompt info
- [ ] Implement `DELETE /api/prompts/:id` — return `204` on success
- [ ] Implement `POST /api/prompts/:id/move-up` and `move-down` — return `200`
- [ ] Validate request bodies and return `400` with descriptive errors for invalid input

## Acceptance Criteria

- All 8 endpoints translate correctly to `ClientRequest` variants
- Invalid prompt IDs return `404`
- Invalid request bodies return `400` with helpful error messages
- Submitting a prompt returns the prompt info with assigned ID
