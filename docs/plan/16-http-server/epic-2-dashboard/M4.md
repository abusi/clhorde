# M4: Prompt Submission Form

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P0
**Depends on:** M2

## Description

Build the prompt submission UI — a text area with mode selector, worktree toggle, optional CWD field, and submit button.

## Tasks

- [x] Create submission form at the top of the sidebar or as a collapsible panel:
  - Multi-line text area for prompt text (auto-resize, min 3 rows)
  - Mode selector: radio or toggle for `interactive` / `one-shot`
  - Worktree checkbox (`[WT]` toggle)
  - Optional CWD input field (collapsed by default, expandable)
  - Submit button
- [x] Submit via `POST /api/prompts` (REST, not WS — simpler for form submission)
- [x] Clear form on successful submission
- [x] Show inline error if submission fails (daemon down, validation error)
- [x] `Ctrl+Enter` keyboard shortcut to submit
- [x] Disable submit button while a submission is in-flight

## Acceptance Criteria

- Can type a prompt and submit it from the browser
- Submitted prompt appears in the list via WS event
- Mode and worktree settings are sent correctly
- Form clears after successful submission
- Error feedback shown on failure
