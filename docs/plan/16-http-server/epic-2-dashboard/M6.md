# M6: Filter & Search

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P1
**Depends on:** M3

## Description

Add a search/filter input above the prompt list that filters prompts by text content and/or status.

## Tasks

- [x] Add search input above the prompt list
- [x] Filter prompts client-side as the user types (case-insensitive substring match on prompt text)
- [x] Add status filter buttons/chips: All, Pending, Running, Completed, Failed
- [x] Combine text search and status filter (both must match)
- [x] Show match count (e.g., "3 of 12 prompts")
- [x] Clear filter button / `Esc` to reset
- [x] Preserve filter across WS state updates (new prompts that match should appear)

## Acceptance Criteria

- Typing in search box narrows the prompt list instantly
- Status chips filter by prompt state
- Filters combine (text + status)
- Filter persists when new events arrive
