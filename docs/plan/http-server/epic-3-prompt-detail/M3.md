# M3: Follow-up Input

**Epic:** [Epic 3 — Prompt Detail](../epic-3-prompt-detail.md)
**Priority:** P1
**Depends on:** M1

## Description

Add an input bar at the bottom of the output viewer for sending follow-up messages to running one-shot prompts (Interact mode equivalent).

## Tasks

- [ ] Show input bar at the bottom of the content area when viewing a running one-shot prompt
- [ ] Text input with send button and `Enter` to submit
- [ ] Send via `POST /api/prompts/:id/input` with `{ "text": "..." }`
- [ ] Clear input after successful send
- [ ] Hide input bar for completed/failed/pending prompts
- [ ] Hide input bar for interactive prompts (they use xterm.js keyboard input instead)
- [ ] Show visual feedback when input is sent (brief flash or checkmark)

## Acceptance Criteria

- Can send follow-up text to a running one-shot prompt
- Input appears in the prompt's output stream
- Input bar only visible when applicable
