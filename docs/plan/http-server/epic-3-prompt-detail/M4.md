# M4: Kill / Retry / Resume Controls

**Epic:** [Epic 3 — Prompt Detail](../epic-3-prompt-detail.md)
**Priority:** P1
**Depends on:** M1

## Description

Add action buttons in the prompt detail header for killing running workers, retrying failed/completed prompts, and resuming with `--resume`.

## Tasks

- [ ] Add action button bar in the prompt detail header area
- [ ] **Kill** button: visible for `Running` prompts, calls `POST /api/prompts/:id/kill`
  - Confirm dialog before killing ("Kill worker for prompt #N?")
- [ ] **Retry** button: visible for `Completed` and `Failed` prompts, calls `POST /api/prompts/:id/retry`
- [ ] **Resume** button: visible for `Completed` and `Failed` prompts, calls `POST /api/prompts/:id/resume`
- [ ] **Delete** button: visible for all prompts, calls `DELETE /api/prompts/:id`
  - Confirm dialog before deleting
- [ ] **Move Up / Move Down** buttons: visible for `Pending` prompts, calls `POST /api/prompts/:id/move-up` and `move-down`
- [ ] Disable buttons while action is in-flight
- [ ] Update UI state from WS events after action completes

## Acceptance Criteria

- Buttons appear based on prompt status
- Kill stops a running worker
- Retry and Resume create new worker runs
- Delete removes the prompt from the list
- Move up/down reorders pending prompts
- Confirmation dialogs prevent accidental kills/deletes
