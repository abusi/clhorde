# M8: Static File Serving

**Epic:** [Epic 1 — HTTP Bridge](../epic-1-http-bridge.md)
**Priority:** P1
**Depends on:** M1

## Description

Serve the JS frontend static assets from the `clhorde-web` binary. Support both compile-time embedding (single binary) and a `--static-dir` override for development.

## Tasks

- [x] Add `include_dir` crate dependency for compile-time asset embedding
- [x] Create `static/` directory with a placeholder `index.html`
- [x] Implement embedded asset serving as the default — fallback handler serves files from the embedded directory
- [x] Implement `--static-dir` override — when provided, serve from the filesystem instead of embedded assets
- [x] Serve `index.html` for all non-`/api/` routes (SPA fallback routing)
- [x] Set appropriate `Content-Type` headers based on file extension
- [x] Set `Cache-Control` headers (long cache for hashed assets, no-cache for `index.html`)
- [x] Wire the static file handler as the fallback route in the axum router

## Acceptance Criteria

- `GET /` returns `index.html`
- `GET /app.js` returns the JS file with `Content-Type: application/javascript`
- SPA routes like `/prompts/5` fall through to `index.html`
- `--static-dir ./dev-assets` overrides embedded files
- `/api/*` routes are not affected by the fallback
