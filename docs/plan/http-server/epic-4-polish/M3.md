# M3: Token-based Authentication

**Epic:** [Epic 4 — Polish](../epic-4-polish.md)
**Priority:** P2
**Depends on:** Epic 1 M1

## Description

Add optional token-based authentication for securing the web interface when bound to non-localhost addresses.

## Tasks

- [ ] Add `--auth-token` CLI flag and `CLHORDE_WEB_AUTH_TOKEN` environment variable
- [ ] When token is set, require `Authorization: Bearer <token>` header on all `/api/*` requests
- [ ] WebSocket upgrade requests must include the token as a query parameter: `/api/ws?token=<token>`
- [ ] Return `401 Unauthorized` with `{ "error": "Authentication required" }` for missing/invalid tokens
- [ ] When binding to non-localhost (`--host` != `127.0.0.1` / `::1`) and no token is set, print a warning on startup: "Warning: serving without authentication on a network interface"
- [ ] Add login page in the frontend: token input field, stored in `localStorage`
- [ ] Attach token to all fetch/WS requests from the frontend
- [ ] Add CORS middleware (disabled by default, `--cors-origin` flag to enable for development)

## Acceptance Criteria

- Localhost use works without any token (zero-friction default)
- Non-localhost with token rejects unauthenticated requests
- Frontend login page stores token and attaches to requests
- Warning printed when serving on network without auth
