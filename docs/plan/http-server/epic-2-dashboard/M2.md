# M2: WebSocket Client & State Management

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P0
**Depends on:** M1

## Description

Implement the JS WebSocket client that connects to `/api/ws`, maintains local application state from daemon events, and provides a reactive update mechanism for the UI.

## Tasks

- [ ] Create `static/app.js` with module structure
- [ ] Implement `DaemonClient` class:
  - `connect()` — open WebSocket to `/api/ws`
  - `onEvent(callback)` — register event handler
  - `send(clientRequest)` — send `ClientRequest` JSON
  - Auto-reconnect on disconnect with exponential backoff (1s, 2s, 4s, max 30s)
  - Update connection status indicator on connect/disconnect
- [ ] Implement `AppState` class:
  - Holds current `prompts`, `maxWorkers`, `defaultMode`, connection status
  - `update(daemonEvent)` — apply incoming event to local state
  - `onChange(callback)` — notify UI of state changes
- [ ] On initial connect: fetch full state via `GET /api/state` to hydrate, then rely on WS events for incremental updates
- [ ] Handle daemon restart gracefully (re-fetch full state on reconnect)

## Acceptance Criteria

- WebSocket connects on page load, reconnects on disconnect
- Connection status indicator reflects real state
- Console logs show incoming events (for debugging)
- Full state hydrated on connect, incrementally updated thereafter
