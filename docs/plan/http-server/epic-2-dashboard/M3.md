# M3: Prompt List View

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P0
**Depends on:** M2

## Description

Render the prompt list in the sidebar with status badges, mode indicators, and real-time updates. Clicking a prompt navigates to its detail view.

## Tasks

- [x] Render prompt list from `AppState.prompts`
- [x] Each prompt row shows: ID, status badge (color-coded), mode icon (interactive/one-shot), truncated prompt text, worktree indicator `[WT]`
- [x] Status badges: `Pending` (yellow), `Running` (blue/animated), `Completed` (green), `Failed` (red), `Idle` (gray)
- [x] Sort prompts: running first, then pending, then completed/failed (most recent first)
- [x] Clicking a prompt row updates URL hash and shows detail in the content area
- [x] Selected prompt row highlighted
- [x] List updates in real time as WS events arrive (new prompt, status change)
- [x] Show empty state message when no prompts exist

## Acceptance Criteria

- Prompt list reflects daemon state accurately
- Status changes animate/update without full re-render
- Clicking a prompt selects it visually and updates the content area
- New prompts appear in the list immediately when submitted (from any client)
