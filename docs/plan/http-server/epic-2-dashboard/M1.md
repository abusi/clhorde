# M1: HTML/CSS Scaffold & Dark Theme

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P0
**Depends on:** Epic 1 M8

## Description

Create the base HTML structure, CSS custom properties, and layout grid for the SPA. Establish the visual foundation — dark theme, typography, spacing, and component primitives (cards, badges, buttons).

## Tasks

- [x] Create `static/index.html` with semantic HTML structure:
  - Header (title, connection status indicator)
  - Main area split: sidebar (prompt list) + content area (detail view)
  - Footer (worker count, daemon status)
- [x] Create `static/style.css` with CSS custom properties for theming:
  - Dark background (`#1a1a2e` / `#16213e` palette or similar)
  - Monospace font (system monospace stack)
  - Status colors: pending (yellow), running (blue), completed (green), failed (red), idle (gray)
  - Card, badge, button, input primitives
  - Responsive layout (sidebar collapses on narrow screens)
- [x] Add a connection status indicator (green dot = connected, red = disconnected)
- [x] Verify the page loads cleanly from `clhorde-web` with no console errors

## Acceptance Criteria

- Page loads with dark theme at `http://localhost:3120/`
- Layout has header, sidebar, content area, footer
- CSS variables allow easy theme tweaking
- No external CSS dependencies (self-contained)
