# M5: Worker Count & Config Controls

**Epic:** [Epic 2 — Dashboard](../epic-2-dashboard.md)
**Priority:** P1
**Depends on:** M2

## Description

Add controls in the footer/header area to adjust max workers and default prompt mode.

## Tasks

- [ ] Display current max worker count and active worker count in the footer
- [ ] Add `+` / `-` buttons to adjust max workers (range 1–20)
- [ ] Call `PUT /api/config/max-workers` on change
- [ ] Display current default mode
- [ ] Add toggle to switch default mode between `interactive` and `one-shot`
- [ ] Call `PUT /api/config/default-mode` on change
- [ ] Reflect changes in real time (WS event confirms the update)

## Acceptance Criteria

- Worker count displayed and adjustable from the UI
- Default mode displayed and toggleable
- Changes persist (reflected in daemon state on refresh)
