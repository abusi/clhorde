CLI Commands (clhorde-cli)

Scheduler (clhorde-cli flow)
flow daemonRun watcher in cwd
flow draftsList unqueued changes
flow queue <name>Write .clhorde-ready
flow unqueue <name>Remove marker
flow status [name]Workflow state(s) + blocked_by
flow apply <name>One-shot dispatch
flow retry <n> --section 3.2Re-dispatch a section
flow cancel <name>Cancel workflow
flow archive <name>Run archive prompt
flow propose <idea...>Spawn /opsx:propose
flow templates path|editUser template dir
